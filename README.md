A summary of this project and what I learnt:

-How to build a simple but effective application.

-I set up our MongoDB database that keeps track of all of our events.

-Created API endpoints for creating different events.
Used an API client to submit them (HTTPIE).

-Then I fetched those events, displayed them and rendered the event-details page.

-Within it, I created another server action to fetch all the similar events (server actions)

-Then I learnt about caching the entire page, so its not making a request to the database every time but once per hour.

-I learnt how to use Posthog for data-tracking & analytics.

-Then I learnt how developers, anno 2026, use AI to our advantage. Through Warp.

-Then lastly, I used Code Rabbit to review our code.
